# 像素蛋糕方法在 Cos 修图中的迁移

2026-10-04 整合官方指南正文、2 篇原作者文章、既有个人案例及实际操作画面核读。12 个视频 URL 均有已核读实际帧；按已确认的 V04 / V12 同作品镜像关系去重，记录为11组作品，不声称文件或逐帧完全相同。具体事实和缺口见 [案例记录](pixcake-cos-cases.md)。V06 的色彩段5帧、蛋糕段6帧、PS/蛋糕对照15帧及 V09 的16帧已收尾；采样请求完成与连续全片观看分别记录，后者仍未验收。

目前没有连续全片观看、原照片或导出质量的完整验收。可引用已看清的局部界面、范围和状态；下列 PS2020 方法是我们的迁移候选，须在用户原图验证，不是复现蛋糕算法或新增统一配方。时间只定位证据，滑杆值只描述该样图，不作为百分比、PS 等效值或默认强度；字幕、简介与平台文稿不能补出未见动作。

## 按照片选模块

| 当前场景 | 优先处理与复用 | 单片必须决定 |
|---|---|---|
| 白发/白衣的亮调场照 | 原图曝光与白平衡→主体/背景→皮肤→假发/服装→必要美型；保留白色层次 | 脸颈肘的色差、白发的角色底色、衣物高光是否有细节 |
| 顶光、混合灯光或粉蓝染色 | 主光方向→脸/颈/身体的明暗与色彩→发衣的溢色→轮廓过渡 | 有来源的彩光保留多少，取消光源后哪些表面必须同步纠正 |
| 自然美型 | 原姿态与透视→整体轮廓→连贯局部调整→邻域光影与妆造 | 收缩位置与幅度、关节锚点、衣袖/假发造成的体型错觉；不复制旧位移 |
| 纸箱遮挡或半合成 | 构图与鞋子取舍→可删/需推测区域→保护可见原人物→局部修补→整套光线融合 | 隐藏结构是否有参考、接触阴影、发丝边缘与残留彩光；背景清理不等于恢复真实身体 |

这些是问题分工模板；不要把所有模块自动加到每张照片，用户只要求补光时保持该范围。

## 自然美型、遮挡与光线一起决定

1. **先诊断光、色和形，再决定责任层。**看主光方向、人物/背景光比和粉蓝染色来源。鼻旁硬线先区分鼻翼、修容、现场阴影和旧蒙版接缝；脸颈、肘部先区分色差与明暗。明确的轮廓问题可以直接受控变形，不必为每张图强行磨皮或补光。
2. **几何按完整部位推进。**肩—上臂—肘—前臂共同设置锚点与渐变位移；下颌—颈—肩连同假发、领口一起看。协调不要求各处等量收缩，可以有明显改善，但不能只收上臂中部形成凹陷。侧头本身不作必改项；小幅姿态呈现调整后检查头颈连接、视线和相邻背景线。新视角或大量隐藏结构补绘另列为合成。
3. **纸箱先解决构图，再解决重建。**比较裁剪/保留部分前景、仅删掉人物外侧的纸箱、或在当前授权内重建遮住人物的部分。先核朝向、画幅与人物位置，V11 那类方向变化另列构图方案，不叫轻微姿态手修。保鞋方案先保住鞋边、腿脚关系、地面透视与接触阴影；不保鞋方案先用裁剪判断视觉重心。隐藏脸颈或身体优先利用可信的同拍参考；没有参考时把补绘明确当作推断，不称恢复原本真实结构。
4. **取消光源要同步改表面。**换景后决定粉光是否仍有来源，连看皮肤、蓝发内部、服装、鞋面与地面反射。原人物 RGB 内的粉色不能只靠收紧 alpha 蒙版消除；蓝发切面也不能只羽化。分别处理溢色、透明发丝方向和背景过渡，并保留合理轮廓光及体积阴影。先核鼻影、颈下、肩臂、衣物、接触阴影和反射，再决定是否加辉光，不用辉光遮住融合错误。
5. **同条件验收完整连接。**同照片、同倍率、同裁切开关目标层对比，再看整体姿态与改善是否可见。原图局部看鼻旁、脸颈肩、整臂关节、发丝、白色材质和道具。白底提亮另查白袜、白手套与地面是否混合；更白不等于层次更好。视频高清截图不能代替这项原片验收。

这些实施判断结合了 [NS01—NS04 个人案例](personal-cases.md)：上臂凹陷、肘部上下色差、鼻旁硬线、粉边和蓝发切面。NS03 只有鼻旁柔化获明确局部认可；其他技术或专项检查不升级为用户接受，更不把这些偏好变成所有照片的统一增白或瘦脸目标。

## 复用以提速

先按光线、角色妆造和相近景别分组，选一张代表片，完成当前用户需求并验收，再保存该组的处理结构。文章 [A01/A02](pixcake-cos-cases.md)有预设与快返经验，V08 / V10 实际展示组合预设的包含项及保存界面，官方 G08/G13 说明按功能复用；这些都不是本机批量质量或速度实测。

| 模块 | 可复用 | 重新确定 |
|---|---|---|
| 基础曝光与风格 | 建层顺序、命名、可开关风格组 | 各图曝光/白平衡、高光与背景光比 |
| 肤色与皮肤 | 责任层分类、保护妆面和纹理的流程 | 脸颈肘取样、蒙版、强度和合理阴影 |
| 自然美型 | 先整段协调、保护关节及道具的判断方式 | 每图几何范围、实际锚点和位移；不保存通用身体坐标 |
| 发衣与背景 | 结构/碎瑕疵分工、局部引入合成的层结构 | 发丝/蕾丝选区、背景重建内容、溢色与接触阴影 |
| 输出与验收 | 现有 PS runtime 的合并调用、预览/导出流程 | 当前请求的裁剪、格式、母版与目标局部 |

在同一 PSD 中保留原片、责任层和最近稳定状态，统一预览尺度做模块开关对比。先确认蒙版，再叠效果；反馈到来时只改对应光色、几何、发丝或补景层，并复查受影响的连接，不每次重新跑整图或全尺寸导出。不要用新模糊层掩盖旧凹陷、硬边和错误光影。

稳定母版一次派生当前需要的裁剪、JPG 与 PNG；导出副本不倒灌为编辑母版。保留尺寸、位深与色彩配置，交付检查按 [现有生产参考](production-retouch.md)执行。潜在提速来自少往返导出、尽早确认选区、同组仅复用底色和直接返修责任层；本轮没有测得复杂修图用时，也不把素材库选择、自动播放到片尾或较短教程片长当效率证据。

未来用同等照片与验收范围记录实际耗时，才判断提速多少；不把教程标题、厂商宣传或单次脚本基准当整张复杂修图耗时。

## 与本用户经验的关系

上臂中部凹陷、肘部仍暗、鼻旁硬线、蓝发切面和粉光抠图感，继续以 [个人案例](personal-cases.md)及当前意见判断。本文提供分区与复用方式，不增加统一瘦脸、大眼、直角肩、拉长脖子或全部增白目标。协调可以有明显改善，是否动形由本图收益和当前授权决定。
