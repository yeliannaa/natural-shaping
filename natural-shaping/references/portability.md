# 移植与首次使用

整个 `natural-shaping` 文件夹是一个独立 skill；保留目录结构后，放进目标应用支持的技能目录。不需要安装原作者的其他修图 skill。首次使用先确认目标应用已识别 `SKILL.md`，再用合成小图验证实际要用的执行路线。

## 路径约定

- Markdown 链接相对于**链接所在文件**解析；`SKILL.md` 所在目录是技能根。脚本和文档均随包携带，不应依赖原作者机器的目录。
- 执行者根据本次读到的 `SKILL.md` 位置取得技能根，根据用户授权的工作目录取得任务根；必要时解析为本机绝对路径传入 Photoshop 或命令行。可移植意味着没有固定机器路径，并非取消运行时路径校验。
- 默认不向技能安装目录写照片、PSD、预览、日志、Python 环境或模型缓存；这些属于任务目录或用户选择的缓存目录。源图只读，产物使用新文件名。
- 示例中的 `SkillRoot`、`JobRoot`、输入文件及画布坐标均由当前任务提供。包含空格或中文的路径须通过结构化参数传递，PowerShell 使用 `-LiteralPath` / `Join-Path`；不得拼入未经转义的 shell 代码。

## 能力与依赖

| 路线 | 需要目标环境提供 |
|---|---|
| 看图诊断、构图与验收 | 本地文件读取及图像查看能力；生成的参考图不能替代真实证据 |
| 原生 PS 精修 | Photoshop 与可执行 ExtendScript 的连接；包内 runtime 使用 ES3/传统 JSX，历史实测 Photoshop 21.2.9，其他版本先冒烟验证 |
| 局部生成或混合精修 | 当前应用可用且获授权的图像编辑能力；本包不附模型、API 密钥或账户，不固定型号 |
| 会话内交互对照 | 当前应用的可视化能力；无此能力时生成等尺度、限高静态对照并保留原尺寸成片 |
| PNG 文件验收 | PowerShell 的 .NET 编译能力；[无损压缩脚本](../scripts/recompress_png.py)另需 Python 3.11+，无第三方依赖 |
| 自动主体蒙版（可选） | 独立 Python 环境、CPU 推理依赖及模型；见[蒙版工具](mask-tools.md)，不是使用整个 skill 的前提 |

skill 本身不会安装软件、授予工具访问权或搬运其他应用的连接。缺少一种能力时说明实际限制，选择当前可执行的路线；不要把计划、提示词或草图说成已经完成的精修。

## 调用参数约定

文档中的 PowerShell 示例均采用参数块：把代码存到**任务目录**中的 `.ps1` 后，传入本次技能根与任务根。`SkillRoot` 是含 `SKILL.md` 的现有文件夹；`JobRoot` 是已授权的现有任务文件夹。相对参数按调用时的工作目录解析。

Photoshop 示例是函数，执行器把当前解析后的路径和已打开文档的唯一名称作为参数传入。输出根必须与 `allowlistedOutputDirs` 精确匹配；这个列表不能代替宿主环境的实际写入权限。

## 首次验证

使用新建的合成文档验证本次会用到的曲线、蒙版、预览与原生导出；确认原文档未被覆盖、产物尺寸/位深/颜色定义正确。只检查本次执行的功能，不用一项成功宣称全部工具或所有版本兼容。发生超时先读 manifest 与实际图层，确认完成状态后再决定续跑。

## 包内资料与校验

案例图、已核读教程帧及笔记按问题读取；不是每次使用都打开全部资料或访问全部外链。外链保留来源，本地已携带的证据无需再次下载。历史记录中的 `origin-not-bundled:` 或 `origin:unbundled/` 只是未携带来源标识，不是运行依赖、可点击资源或重放脚本。JSON 的路径基准见各记录的移植说明；主索引使用 skill 根，其余证据通常相对于记录所在目录。历史 SHA256／bytes 属于原始证据，改写后的当前字节以包根 `package-manifest.json` 为准。`assets/evidence` 内的旧记录只作证据阅读，不重放其中的历史命令或照片坐标；执行按主 skill 与随包脚本的现行文档。

在任意工作目录运行 `python <技能目录>/scripts/validate_portable.py` 可校验文件清单、SHA256及显式本地引用；脚本从自身位置定位技能根，不联网、不修图、不写包内文件。检测不代替图像验收或执行环境测试。

随包保留原使用者的少量照片局部与最终 JPG 作为风格/失败证据，不含完整拍摄库、PSD、API密钥、会话配置、虚拟环境或模型权重；第三方教程片段保留原作者及来源归属，不附整个视频或第三方付费插件。
