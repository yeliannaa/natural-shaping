## 视频转为规则的条件

1. 分开记录实际帧观察、全部主要操作阶段检查、连续全片观看、可引用局部事实和可采用用户规则。只检查了某几帧就列帧，不把首末时间写成已连续观看区间；到片尾或自动重播不标“已看完”。
2. 记录 `原图问题 / 处理顺序 / 选区和保护区域 / 实际工具 / 关键时间点 / 效果与失败点 / 有效条件`。无法看清的参数留空，不用转写猜数字。
3. 分清普通磨皮、传统几何调整、生成式重绘。检查眼鼻口、肩臂关节、角色妆造、道具、发丝和周边线条。没有原尺寸资料，不声称验证全部细节或无损。
4. 从明确的局部事实提出 PS 候选，注明选区、生成/原像素区别和缺口；只有在相应操作与效果已核对、用户原片另行验收后才升级为采用规则。软件控件或预览可见不代表 PS2020 有同样自动能力，也不代表本用户接受。
5. 新来源没有可核的实际操作画面时只保留候选；浏览器、登录或播放受阻时说明实际限制，不拿简介或平台总结替代视频验收。
