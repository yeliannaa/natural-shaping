# 审美参考库

按照片问题选择参考，结合图片观察人物、妆造、结构与光色的处理方式。具体设计以当前照片的确认方案为准。

## 自然精修与高P

| 档位 | 适用目标 | 处理重点 |
| --- | --- | --- |
| 自然精修 | 保留原神情、角色妆造和摄影质感，改善肤质、五官及适用比例 | 联看全脸、假发、颈肩和身形，按实际需要调整 |
| 高P精修 | 明确设计整体脸型、五官、妆面、表情、发衣、人物比例及场景光色 | 先展示源图确认计划，再完成整体设计与连接检查 |

全局光线与人物精修一起处理，让脸、衣服、身体和场景的受光协调。表情联看眼睑、目光、面颊与嘴角，唇色保留清楚妆感；通透和柔和通过明暗、色彩及材质层次共同呈现。

## 工具分工

原生PS处理精确轮廓、光色、材质和接缝，Image与可选Qwen提供整体或局部设计候选。根据结果选择整图采用、局部融合或参考，并检查整图观感、原尺寸细节与受影响连接。

公开库保留中性处理方法和公开示例；个人反馈、排序、本机路径与训练资料保存在本地。
