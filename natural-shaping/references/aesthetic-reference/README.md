# 审美参考库（公开精简稿）

这份资料从实际修图反馈中整理适用条件，供判断问题和选择参考使用。它不是固定美颜模板，也不代表每位使用者的偏好。当前照片的确认方案优先；采用参考前仍应查看对应图片。

## 自然精修与高P

| 档位 | 适用目标 | 保护与验收 |
| --- | --- | --- |
| 自然精修 | 在保留原神情、角色妆造和摄影质感的基础上，明显改善肤质、五官及适用比例 | 全脸联看假发、颈肩和整体身形；轻修有效时不强求大幅变形 |
| 高P精修 | 用户明确选择后，设计整体脸型、五官、妆面、表情、发衣、人物比例及场景光色 | 先展示源图确认计划；保留可识别特征和可信连接；不能把一种肤色或脸型套到所有人物 |

整体光线应与人物精修同步考虑。脸变亮后，衣服、身体和场景仍暗闷，不等于完成全图。表情需联看眼睑、目光、面颊和嘴角；唇色既要避免过鲜，也要保留妆感。具体强度由本图、角色与当前要求决定。

## 参考状态怎样使用

- **整图认可**只属于具体版本，不能继承到后来另做的候选；也不意味着所有区域都适合作为新任务的监督目标。
- **局部认可**只对已检查的区域生效。腕袖、补边或发丝完成，不能推成整图已达标。
- **已保存／已收录**只说明文件或示例存在；没有认可依据时不补写认可。待验收和撤回的候选也不能自动当负例。
- 成片可以展示外观，不能单凭一张成片证明修前后的改动量、算法或参数。检索到参考后仍需实看。

## 当前边界

通透和柔和不等于一味增白、减阴影或削弱妆面。高P中曾有效的偏白、减少过粉处理，仍需结合角色、原妆和环境判断。主观气质标签、固定脸型、身体偏好和案例之间的排名不作为公共预设。

原生PS、内置Image和可选Qwen按问题分工；采用生成结果后还要检查整图、原尺寸和完整受影响连接。整图生成、局部融合、仅作参考或回退都是可行结果，当前资料不足以宣称某个后端始终更好。

公开库仅保留中性条件与已经公开的示例链接。私人原始反馈、个人排序、身份线索、本机路径、原图指纹、训练清单和权重不在本库中。
