# 身体轮廓与姿势协调

当已授权调整身体轮廓、头肩姿态，或修复此前美型造成的轮廓缺陷时读取本参考；执行沿用[共享生产规则](production-retouch.md)。只有皮肤亮度问题时先读光影参考。“自然美型”允许在用户已选范围内明显、协调地优化，不要求每个部位都变瘦。

本用户主要修 Cos 照，判断标准是有充分可见提升的精致人像：脸型与五官更精致、腰线更清楚、腿部比例更舒展，并协调适用的局部轮廓。此前的轻微提升未达到用户目标，分步受控调整须以最终精致程度、本人感和角色妆造共同定幅。没有明显缺陷时仍评估改善收益，预计有收益就受控试调；以同画幅对照的整体效果决定保留幅度，不要求变化接近不可见，也不固定每张缩脸、收腰或拉腿。

### 先决定改变什么

- 区分姿势、透视、衣物体积、光影和真实外轮廓。亮肩暗臂不一定是粗细差，假发蓬松也不等于头部比例需要改。
- 用一条短记录确定：问题位置 → 图像证据或主观偏好 → 目标外观与修改方向 → 关联部位 → 固定接触约束与可联动结构锚点。支撑或握持等关系需要保持；五官点、腰线、关节可在当前授权范围内随整体比例协调移动，并检查结构与受力。不要把所有锚点解释为像素坐标锁死，也不要用“更好看”代替具体方向。
- 本图构图草图经用户确认后，在选定范围内自主完成常规协调调整，不逐部位重问。要改变已确认取景、姿态或关键元素方案时，按主 skill 更新草图并等待对应确认；相互排斥的审美方向或关键身份改变也先澄清。普通局部返修沿用仍成立的确认，不强制输出三张候选。
- 位移大小按这张图的分辨率、身体朝向、轮廓宽度、纹理和背景确定。记录实际操作与效果，不给所有人套同一个缩瘦比例或液化滑杆值。

### 整段轮廓一起考虑

| 区域 | 联动范围与锚点 | 合格的变化 | 需要返修的迹象 |
|---|---|---|---|
| 脸 | 面颊 → 下颌 → 下巴，与假发及颈肩联看；眼鼻口、表情与颈饰 | 精致感改善，轮廓连续并保留本人感，未把假发蓬松误判成脸宽 | 面颊凹陷、下巴过尖、嘴角牵拉、脸颈或发际脱节 |
| 上臂 | 肩峰 → 臂外侧 → 肘尖 → 前臂；袖口与内侧折痕 | 弧线连续，关节位置和受力仍成立；变化逐渐接回未动区域 | 只收中部形成凹陷，肘部突然变宽，袖口与皮肤分离 |
| 肩颈 | 下颌 → 颈侧 → 锁骨 → 肩线；耳、领口 | 长度、方向与头的位置一致；阴影随形体成立 | 半边脖子突然细或白，颈侧直线切断，锁骨方向冲突 |
| 腰与服装 | 胸腹 → 腰 → 髋；扣件、花纹、接缝 | 身体与衣服一起协调，保留布料厚度和褶皱受力 | 腰陷进衣服，硬饰件弯曲，花纹重复，手和腰错位 |
| 腿与脚 | 大腿 → 膝 → 小腿 → 脚踝；袜口、鞋底与地面 | 保留屈伸角度、前后层次、接触位置与鞋形 | 膝部无关联漂移、腿段衔接或受力失真，鞋被拉长，脚底悬空 |

“整体协调”不等于每个点等量内移。把需改变的弧线作为一个区域，以关节、接缝和接触点限制位移，逐渐过渡到不需要改变的位置。大画笔只能帮助平滑，不能替代关节判断。

颈部长短争议先联看头大小、下颌、发尾、颈饰、肩线和领口；取景、肩位及衣领可能改变观感。按授权试调时同时看整图头身关系和颈肩过渡，不只缩短裸露皮肤段。阿昭案例说明局部光色自然仍可能留下整体比例争议，不推导为所有人像默认缩颈。

### 微调姿势

1. 先看画面倾斜还是人物倾斜。背景垂线、身体中轴、头的朝向和角色动作一起判断，不把双眼水平当作唯一标准。
2. 侧头、含胸或肩高差可能属于表情和动作。原姿势成立时，可改善轮廓、头发体积或局部肩线，让它更利落，不机械扶正。
3. 只有现有像素可支持的细调，才优先用局部变换或液化。头—颈—肩一起检查，不能单独旋转头后留下扭断的脖子。
4. 手持道具、靠墙、坐地等姿势有接触约束。保留手—道具、身体—支撑物、脚—地面的关系；同时复核衣褶和接触阴影。
5. 隐藏的肩、肘、腰或背部没有可核实轮廓。把依据可见锚点提出的关节位置标为“推断”，不要据此给出精确的身体测量。新增可见区域按遮挡重建处理。

### 快速制作与验收

- 全图先分别判断脸、腰、腿是否更协调、改善是否可见；局部显宽还要检查其与邻近部位、衣装和透视的关系。仅确认没有变坏不足以完成美型；收益不足时按优先级处理尚未达标的区域，每项完成后复查其余不足。各区域按自身收益调节，不能因为一个局部改善就将脸、腰、腿全部记为完成，也不要求所有区域同幅度变化。
- 在可撤回的几何层上处理整段轮廓，从影响最大的部位开始，再处理其他必要部位；不把一张图的位移场套到另一张不同姿势的照片。
- 快速整图预览判断变化是否足够明显、比例是否协调；局部原生细节判断凹陷、接缝、关节和背景弯曲。
- 验收覆盖改动区域及相邻两端，不能只截取最窄处证明成功。若形体过渡更怪，重做该段或退回稳定版本，不用模糊掩盖几何错误。
- 校准脸颈和身体光影后再判断最终显瘦程度：亮度变化本身可能改变体积感。普通局部试修不必每次导出整套全尺寸图片。
