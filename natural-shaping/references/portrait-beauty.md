# 人像美颜与覆盖检查

更新：2026-10-07。每张完整自然美型必读；局部返修只复核改变及受影响区域。目标是皮肤明显更细腻、五官精致、身体线条和比例充分改善，同时保持本人感与妆造。以下结合历史案例提供者要求、原作者教程与实际经验；软件有功能不等于本机已实现。整体验收与返修闭环见 [验收与返修](quality-review.md)。

## 每次检查并完成什么

先看全图，再看本图原尺寸可见区域。内部为下列类别记录 `人物／区域 / 观察与目标 / 关联锚点 / 实际动作 / 版本与结果`，状态沿用验收参考的已改善、检查后保留、待修／待核、受限未完成。群像按本图纳入精修的成员逐人记录，不能用一人的肤质改善代替全组覆盖；背景路人不自动成为精修对象。首版先完整评估所有适用类别，再按收益处理，未完成项明确留下。

| 类别 | 必查内容 | 完成条件 |
|---|---|---|
| 肤质与妆面 | 临时痘点、明显粉底/干皮结块、零散色斑、过强油光、局部纹理杂乱；是否属于角色妆或识别标记 | 瑕疵减少，皮肤达到本图所需的细腻、平整与通透程度；保留可信纹理、体积及完整眼线、睫毛、闪粉、妆痣和装饰。 |
| 面部光色与立体 | 泛红/色块、眼下与鼻旁过硬过渡、脸颈色差；结构阴影与主光是否成立 | 杂乱光色被改善，眼窝、鼻翼、嘴角、下颌仍能解释结构，脸颈自然衔接。 |
| 气色与唇妆 | 嘴唇是否孤立灰黑／发白、眼下口周是否脏暗、腮红与角色妆、脸颈及可见手部色调 | 保留妆色意图，解决不相容的灰暗和断层；唇缝、纹理与高光仍在，不把深唇妆统一刷红或把肤色统一漂白。 |
| 脸型与五官协调 | 面颊—下颌—下巴的连续性、脸与假发/头饰比例、侧头透视、眼鼻口及表情；主动评估精致感与主观比例优化 | 脸型和适用的眼鼻口关系得到足够明确的精致化，保留本人感；本来已达到目标或充分试调确无收益时可保留，不能因没有明显缺陷或只做肤色就默认完成。 |
| 肩颈与双臂 | 头颈连接、肩线、肩—臂—肘—前臂、手与道具接点，左右受光 | 整段轮廓与关节协调；肤色连贯，不能只收中段或单独漂白肘尖。 |
| 腰髋与衣装 | 胸腹—腰—髋的过渡、腰线清晰度、软衣蓬起/横褶/亮块、左右朝向、手压衣料、接缝与硬饰件 | 有收益时整理衣装体积或连续调整可见轮廓，突出腰线；不把裙蓬或硬甲板当肉，不因遮住真实腰就跳过可见衣装协调。 |
| 可见腿脚及整体比例 | 可见腿段与腰胯起点、膝踝、裙甲/袜口/靴子比例、屈伸关节、前后透视、地面接触及头身关系 | 有收益时改善腿线连续性或适度调整可见比例，保住关节、鞋形和接触；腿直不等于比例无需优化，出框/遮挡的部分标不可判断。 |

完整自然美型交付前不得留下未说明的待处理项。工具受限则列明，并完成可执行部分；不能把“已检查”记成“已修改”。本图草图经用户确认后可在授权范围内自主美型，不需要逐部位提问，也不需要脸、腰都固定收窄。已经达到本图精修目标，或经适当试调无净收益、反而损害身份的部位可保留；要有原图或试调比较依据，不能仅凭无明显瑕疵或“自然所以不改”跳过。方法失效或工具无法执行需分别记录，不能据此判定该部位没有改善空间。

完整自然美型以脸、腰、腿适用部位有适当且看得见的优化为目标；判断门槛是可见改善收益，不是必须先出现明显显胖或短腿。局部显宽、鼓起或短粗感联看轮廓、光影、衣料、假发和透视，不据照片给人物下胖瘦结论。适用时主动处理，不只列成可选建议；已协调可保留，并说明判断依据。

## 成片目标与处理次序

修前构图拆解、草图展示及用户确认均完成后，先验证会决定方案可行性的结构难点与主光，再落实肤质、脸部及身体的主要收益。普通照片不增加重建试验；背景细修、装饰效果和重复导出不挤占人像精修。

- 肤质：在与该图景别相称的人像查看尺度上，皮肤明显更细腻、光色更均匀；原尺寸仍有可信纹理与妆面。允许适当弱化粗重毛孔和纹理，不要求保留原图每一处纹理的原始强度；同时保住面颊、眼眶、鼻和嘴周的体积。
- 脸型与五官：分别检查轮廓、眉眼、鼻部、唇部与下巴关系，按本图选择有收益的调整，使精致感明确提升。保留本人关键特征与表情，不要求所有部位都动。
- 身体：整图对照能看出适用的腰线、肩臂线条或腿部比例改善；分别处理尚未充分改善的区域，保住衣装形制、关节与接触关系。

每类要同时回答“目标改善是否充分”和“身份、结构、质感是否成立”。只通过后一个检查仍可能修得不足。遮挡或低分辨率不足以支持判断的部位照实标明，不为制造差异编造细节。

## Cos 照的精修目标

在保留本人感的同时，让脸部风格与该角色既有妆造一致。以用户提供的角色或成片参考判断方向；没有明确参考时从原图眼妆、美瞳、假发和服装提取依据，不自行把所有角色改成幼态、大眼或 V 脸。

- 肤质与底妆：整理粉底结块、干皮、局部浮粉与杂乱油光，充分平整干扰性的明暗、颜色和纹理；保留刻意的腮红、修容、卧蚕妆、闪粉、妆痣及面饰。皮肤可以明显细腻，脸、颈、胸口与手臂的完成度和色调要协调；角色白肤按妆造判断，不自动扩大为所有照片的增白规则。
- 眉眼鼻唇：在原妆基础上清理和完善形状、过渡与光泽，使角色表情更清楚、五官关系更精致。妆造保护允许有依据的修整与增强，同时保留眼线走向、美瞳图案、唇妆风格及关键角色标记；不能把浓妆误判为皮肤污点，也不能为了保住原妆而放弃所有精修。
- 假发与脸部：把发际、刘海、鬓发体积与脸型一起看；适用时整理乱丝和块状轮廓，保住角色发色、分区、发饰及合理发丝。假发轮廓可以影响脸的观感，但整理假发不能冒充已经完成五官调整。
- 身形与衣装：协调肩颈、腰线、胸腰髋和可见腿段，让人物比例与角色装束一致。衣料可以随轮廓整理，装甲、饰件、裙撑、鞋与道具保持结构。袜口、手套边缘和露肤处同步检查，避免只精修脸。

同组照片先选一张具有代表性的原片完成这些主要收益，再复用适合该组的处理结构；脸型与身体位移按每张姿态重定。文字修改、文件检查或技术测试通过，只能证明相应检查完成；未经实际原片对照与用户评价，不宣称已经达到像素蛋糕或用户要求的精修效果。

## 皮肤处理要分三件事

**局部瑕疵**：用独立修复层，对明确痘点、临时小伤痕、干皮或粉底结块逐处处理。污点修复自动取样；靠近睫毛、鼻翼边、唇线和发丝时改用修复画笔或仿制图章手动选源并检查。稳定痣点、雀斑、有辨识作用的旧疤痕或不确定标记先保留，角色妆痣、闪粉、卧蚕妆与假睫毛不当作污点。祛斑可以纳入自然美型，但不等于把所有天生标记一并删除。

**颜色与明暗不匀**：局部色彩调整处理泛红/不相容色块，局部曲线或减淡加深处理不流畅明暗。不要全脸降饱和把唇色、腮红和彩色妆一起洗灰。暗区提亮也需匹配色相与邻近皮肤，脸、脖子和身体分区控制、共同验收。

**气色与嘴唇**：先对照原妆和场景，区分深色唇妆、阴影、饱和度不足与调色污染。按需要分别校准局部明暗和颜色，保留唇线、唇缝、纹理及反光；全图看嘴唇是否仍孤立发灰，原尺寸看是否成了色块。联看眼下、口周、脸颈和手的受光，不用整脸增红代替气色。不同成员可有不同肤色与妆色，不追求相同 RGB 或统一白度。

**纹理**：依据本图细节与用户要求的细腻程度，使用分区、可回退的纹理修整；需要分别处理纹理与色调时可用频率分离。没有严重瑕疵仍可有细腻化收益，不因皮肤基本完整就跳过。高频纹理与低频色调分别处理；半径、强度依本图真实细节和分辨率判断，不继承教程数字。8/16位的频率分离组合需按实际实现验证重组；不要拿统一模糊半径或一键动作当完成证明。过度平整后的蜡感不能靠锐化或新增假毛孔找回原细节。

常规小瑕疵可用局部修复；已经达到目标的肌理以必要的明暗整理为主。方法按效果需要选择，不强制建立频率分离，也不把局部修瑕作为所有照片的处理上限。皮肤上的主光高光和关节转折不全部抹掉；是否柔化由效果与妆造决定。

## 脸部美颜不只等于瘦脸

区分轮廓、光影、妆面、表情与镜头角度。侧头时两侧脸宽和眼睛可见面积自然不同，不按左右对称模板纠正；鼻旁暗线先查鼻翼边界、化妆和阴影，不以液化代替光影修整。

有收益的脸型协调可以沿面颊—下颌—下巴分步、连续地调整，也可以补顺局部凹陷或优化与假发体积的关系；方向按本图决定。已授权主观美型时，不要求出现“缺陷”才允许做试调。单步受控便于比较与回退，累计幅度由精致感、本人感、角色妆造和整图比例共同决定，不把“小步”当成最终只能轻修。按收益排序处理必要部位，覆盖不足时继续完善。

眼角/瞳孔、鼻基底、唇角和原表情用于检查身份与结构关系，并非全部坐标锁死。局部五官协调确有收益时可联动调整，保留视线、表情及关键识别特征；多项几何叠加后必须重新看整脸，不能同时扩大眼睛、缩鼻、尖下巴后只检查单个部位。保持斜头的五官排列与面部朝向，检查耳、发际/假发、颈根、颈饰与肩线。大幅转头、新表情或换脸不属于常规自然美型。

按本图选择五官调整，先说明希望改善的外观，再选择光影、妆面或几何；下表提供方向，不是每张图必做的套餐。

| 分区 | 可选择的精致化方向 | 联动检查 |
|---|---|---|
| 眉眼 | 整理眼周明暗与妆线，改善眼部清晰度；比例支持时调整眼形、开合或眉眼关系 | 眼眶体积、视线、两眼透视、睫毛与眼线随形成立，保留原表情和美瞳设计 |
| 鼻部 | 平顺鼻旁过渡、整理鼻梁光影；确有收益时协调鼻翼或鼻部与整脸的比例 | 鼻孔、鼻翼、鼻尖方向及人中连接自然，不把缩鼻和鼻影弱化绑定为同一动作 |
| 唇部与下巴 | 修整唇缘和光泽；需要时协调嘴宽、唇形、下巴形状与下庭比例 | 嘴角、笑容、牙齿、唇妆及颏唇沟关系保持，不能单看唇形或下巴的最窄处 |
| 面颊与轮廓 | 协调脸宽、面颊丰满度、下颌转折和下巴，结合假发体积改善脸部比例 | 面中与五官位置、发际、耳和颈肩连接共同成立，保留有辨识度的骨相 |

妆面可修干净、光泽可协调；提亮眼部需保留眼线、美瞳颜色与合理反光，不新增不符合光源的亮点，不把眼白刷成纯白。

## 腰身与体型的实际执行

明暗和服装先判断清楚，再决定几何。实际收腰时联看胸腹、腰与髋，以及对应衣装外缘、纵向花纹和手势；逐渐接回未改区域。保护硬饰件、扣件、装甲/束腰边、手和道具接点，不能在腰中间造凹洞、把衣服硬件拉弯，或让衣褶失去受力关系。

收窄腰、改变腰段长度与改变上身长度是不同动作，要分别确定收益，不在一次全局缩放里一起改变。双臂、肩颈和腿脚同样沿完整相关轮廓执行。近镜头的手或鞋大可能是距离透视，不自动压小；衣袖/假发外缘可以整理，但不能据它们测量未见身体。几何步骤沿 [轮廓与姿态](shape-and-pose.md)，光影沿 [光影与边缘](tone-and-edges.md)。

真实腰线被遮挡时，可依据可见外缘整理软衣的蓬起与横褶、协调胸腰髋的视觉体积；不必知道真实腰围才能优化衣装。硬甲妨碍腰线时，可评估整件有限位移，但必须保持形制、连接与接触关系，不能把它随软衣收窄而拉弯。

腿部先区分腿段比例、裙甲遮断、靴子体积与取景透视。可见结构支持且预计有收益时，试调局部腿段或上下身的比例关系，保护膝踝和鞋底接触，并检查相邻裙甲；不通过整片纵向拉伸同时拉长装甲、鞋和地面。只能评价可见范围，但遮住部分腿也不妨碍整理已可见腿线的连续性。

整体改善不足时，分别检查肤质、五官/脸型与身体比例的缺口，按收益排序继续处理。效果不足的区域回到原责任层校准范围、方法或程度；已经达到目标且稳定的区域不重复叠加。若收益停止或结构受损，回退失败尝试并换合适方法；现有工具仍做不到时列明真实限制，不无限加强或把未实现的目标改记为无需处理。

## 验收与如实交付

用同一画幅、缩放和颜色显示比较前后。适屏看本人感、妆造、完整比例和改动是否有收益；原尺寸查看皮肤、眼鼻口、轮廓两端与接触处。肤质清爽但脸平、脸好看但颈断、腰窄但衣装扭曲，均不能交付。

把肤质修复/光影、脸型或五官几何、身体轮廓分开开关比较；避免用更亮的全图掩盖形体变坏。出现新硬线、蜡感、重复纹理、关节凹陷或背景弯曲，回到责任层改，不叠模糊。

交付只报实际动作。若脸和腰判断后保留，直说理由；若只做两臂轮廓，不能称脸腰也已美型。用户认可局部不等于接受整张图。
