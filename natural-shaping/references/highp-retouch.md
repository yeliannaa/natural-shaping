# 高P精修：独立的整体设计档

仅在用户明确选择高P，或要求超出自然档的更强整体设计时读取。自然美型仍为默认档；高P按已确认范围加强整体设计。两档共用 [构图确认](../SKILL.md#强制前置构图拆解--可见草图--用户确认--精修)、[人像覆盖](portrait-beauty.md) 与 [三道验收](quality-review.md#三道采用与交付门槛)，不新增逐部位审批。

按需继续阅读[详细控制项、提示词模板与实测设置](highp-controls.md)。其中分开记录设计力度、后端能力、PS单项数值和尺寸链。公开成片可看[竖幅](../assets/examples/yao-highp-portrait-final.jpg)与[横幅](../assets/examples/yao-highp-wide-final.jpg)，原片、局部对照及事后标注复盘见[高P展示页](https://yeliannaa.github.io/natural-shaping/highp.html)。

包内可离线查看[竖幅编号分析图](../assets/evidence/highp/yao-highp-portrait-analysis-map.png)和[横幅编号分析图](../assets/evidence/highp/yao-highp-wide-analysis-map.png)。两图是成片教学复盘，展示“构图／美型／光色／保护”的关系与标注结构。

## 整体设计要回答什么

先从原片与当前要求确定这张照片想呈现的气质，再把具体设计纳入同一方案。按画面需要，联看人物、造型与场景的以下关系：

| 设计对象 | 本图需要明确的关系 | 仍需保护或说明的边界 |
|---|---|---|
| 脸型、五官与神情 | 整体脸型和眼鼻唇／下庭比例，眼神与眼睑—面颊—唇缝联动；按角色设计气质 | 保留本人识别点及合理头向、透视；不套 V 脸、镜像眼或只提嘴角 |
| 身体、体态与衣装体积 | 头肩颈、胸腰髋、肩臂与可见腿段在本姿势下的完整比例；软衣随形整理 | 关节、握点、支撑、前后遮挡、衣装形制与硬饰件可信；隐藏形体为推断 |
| 假发、妆面与配件 | 刘海、鬓发与脸型共同设计，按确认方向精整妆线、修容和发衣层次 | 保留角色发色、分区、美瞳设计与关键标记；无关的换妆、衣装更换不默认包含 |
| 材质与全局受光 | 肤质、发丝、软布、绒毛、珠光和硬件各自的细腻度与反光；脸身共同受光 | 不以全图模糊或漂白替代精修，不把每种材质做成同样锐／亮／滑 |
| 构图、背景与氛围 | 人物占比、视线／动作空间、画边取舍，背景空间与主光色的关系 | 不只压黑背景；保留可信现场层次，新增或删除关键元素按已选范围执行 |

将主观风格设计与拍摄问题修正分开。参考图可帮助说明眼神、比例、妆面和光色关系，不复制参考人物的脸；原片用于识别点、原妆与结构依据。同组沿用设计意图和完成度，各张按角度与受光处理，不匹配五官坐标或强行修成相同神情。包内自然档案例和历史教程可用于借鉴处理方法，高P设计力度按本图目标确定。

## 先展示可审阅的源图确认图

按 [高P确认图的制作要求](composition-and-key-elements.md#高p确认图让设计方向可审阅) 展示整图设计、必要的脸／身体源图细节、光色目标和保护／未知区。图中区分拟改变的比例或神情、拟整理的光色材质与本来成立的内容；标明本图档位、方案版本、“未精修”及有取舍的部分。

确认前只做原片注释、独立取景示意和方向色板，不生成修后效果、不改照片母稿。默认一套推荐，有实际取舍才 A/B；实际展示且可读后按主 skill 等用户选择。同一方案已确认后自主完成其内各部位，不逐项追问；局部返修沿用有效确认。

## 生成与人工收尾如何分工

- **整体设计尚需建立**：当人物比例、假发衣装、全局场光与背景必须共同判断时，用整图作为生成上下文，明确本轮必要改变与保护关系。按候选的整体收益和结构，决定整图采用、局部融合、参考或退回。
- **整体稳定，只剩人物／脸部力度不足**：从稳定版本取完整脸、假发框脸及颈肩上下文，定向完成比例和联动神情，再限定融合。不要反复生成已成立的整图，也不要把眼睛、鼻子、嘴和下颌分别拼成不同的一套关系。
- **精确、局部或剩余问题**：由 PS／可用编辑工具收尾轮廓、普通皮肤与妆面色差、材质反光、发边和实际接缝；已成立的区域保持，精确问题由当前编辑工具直接完成。

后端按当前用户选择、可用能力和平台规则执行；已选择 Image 与本地 Qwen 并行时，按 [双路比较](cos-retouch-engines.md#双后端并行与候选比较) 各出一版同目标候选。没有本地模型不妨碍使用可用的内置编辑。提示词分别写明需要设计的关系和应保持的结构，明确五官与表情的可调整范围。

生成输入上下文和实际采用范围分别决定。按 [原生映射](cos-retouch-engines.md#局部输入与原生映射) 记录裁片与返回尺寸、缩放／填边、源坐标和蒙版；合入后检查颊颌、脸颈及发边接缝。需要更大交付尺寸时按 [尺寸与缩放](cos-retouch-engines.md#尺寸与缩放) 处理，优先考虑已验证的 PS 等比放大；放大时保住已认可候选的整体观感，再检查发丝、蕾丝和珠链。

## 以设计收益验收，不只排除瑕疵

高P仍按既有三道门槛交付。先看已确认的人物气质、比例、妆面与整体造型是否达到本图力度，再查识别点、结构与原生细节，最后查实际合成和导出。同时评估人物设计和整体造型的提升。

对“脸歪”“不够通透”“白与妆不协调”先诊断来源：头倾／透视与新增形变，裸肤色偏与刻意妆色，全局受光与局部明暗分别判断，详见 [人像诊断](portrait-beauty.md#脸部美颜不只等于瘦脸) 和 [光色衔接](tone-and-edges.md#全局场光与肤色方向)。针对诊断结果调整相应维度。

同组最终放在一起检查妆面方向和完成度，保留各张合理的角度与摄影差异。按 [私人档案](personal-data.md) 记录具体版本的检查、认可与后续偏好。
