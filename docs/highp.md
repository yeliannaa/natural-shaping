两张暗场Cos照的完整设计：竖幅侧重脸颈与完整造型，横幅保留前伸手的近大远小和失焦。高P力度由本图目标决定，人物美型、衣装、光色与背景一起判断。

源图1440×2160，成片1569×2160。公开整图分别取1440×2020与1569×2020，裁去底部账号区后等比生成预览；前后独立取景。

## 尺寸链与操作要点

本组使用内置Image完成整体与脸部设计，Photoshop负责融合和收尾。

| 环节 | 本组实测 | 操作要点 |
|---|---|---|
| 竖幅整图 | 已整理目标1569×2160 → Image1069×1472 → PS按高2160等比放大 → 1569×2160 | Preserve Details 2.0／deepUpscale，降噪0；读取返回尺寸后等比放大 |
| 横幅整图 | 已整理目标1536×1024 → Image1536×1024 → PS按宽2160等比放大 → 2160×1440 | 同一PS方法、降噪0；使用已整理工作画面作为输入 |
| 脸部局部 | 准备1024上下文图和640聚焦裁片；实际Image1254×1254 → PS Bicubic缩到640×640，按原裁剪位置贴回 | 按剩余问题选择输入上下文，返回图检查完整头脸，再用蒙版控制合入范围 |
| 局部蒙版 | 本组640局部使用Gaussian半径8px柔化 | 按本组蒙版尺度柔化；更换尺寸或边缘材质时，重新绘制蒙版并调整半径 |

贴回后，在原尺寸检查脸颈、发缘和蒙版过渡。设计目标、提示词与参数试调顺序见[高P详细调参说明](../natural-shaping/references/highp-controls.md)。

## 验收重点

1. 全局光线、脸妆、衣装和背景是否一起改善；白净、粉润与妆色按本图取舍。
2. 整张头脸和同组照片联看，确认眼睛、表情、脸颈、手腕、握点、饰件与透视。
3. 重开实际导出图，在适屏与100%局部复核融合边界、透明材质和衣料纹理，分别检查清晰区域与前景柔焦。
