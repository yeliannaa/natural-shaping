真实案例 / 宫本樱 v9

衣带必须能受力：宫本樱的双手—双带—腰头

以双侧双带、手指、皮肤接触与衣缘的连续衔接为重点，联看构图、美型和材质。

腰腹协调 · 双侧双带 · 手指与材质

整体对照构图与美型拆解四组局部特写怎样验收

COMPOSITION / 整体取景

先看完整画面

收紧头顶空间，补全下方腰头与衣料。结合侧转姿态和同套衣装参考，联看双手牵带、侧腰落点与腰头连接。

READ THE PHOTO / 从具体位置判断

构图、美型与保护一起拆解

按侧转脸、颈饰、衣缘、双侧双带与手指，逐段查看体积和受力关系。

  1. 1侧转脸、发尾、颈饰与斜领口

    红妆与唇缘、发丝层次、颈侧光影、尖角颈饰和白领口的独立边界。

  2. 2左侧双带与下垂手指

    贴肤段、指边转折、两条带的独立走向、原图遮挡与成图腰头连接。

  3. 3右侧双带、夹持指与侧腰落点

    右手运动虚影、夹持处、悬空与贴肤段区别、边缘粗细和侧腰落点。

  4. 4T恤下缘、腹部与松紧腰头

    源图黑前景遮挡、衣缘连续性、腹部体积、腰头褶皱与新增区材质尺度。

01 / 观察与判断

收紧上方空间，同时完整交代腰头

头顶空黑背景、腰腹与下沿黑色前景遮挡，成图完整可见的松紧腰头。

原片与成片
原图：头顶上方有较大黑色天花板与散景灯点，主体脸部在画面中部；下方黑色前景挡住大部分腰头及手下方衣带。 成图：头脸与上身在画面中的占比更大，脸进入上半区；上方空隙收紧，下方可见完整腰头与裙料。双手到腰头的动作不再被黑前景截断。
影响与取舍
人物与牵带动作成为同一个视觉中心；双手到腰头的连接，让补全后的画面保持动作和受力。
处理与保护
收紧头顶空间，沿原有衣缘衔接腰头与裙料，保留脸朝右侧转和双手向腰侧牵带的路径。

02 / 观察与判断

脸部保留侧转、红妆与露齿唇形

刘海下双眼、红色眼妆、鼻旁、唇缘、侧脸下颌和发尾。

原片与成片
原图：黑短发包住侧转的脸，红色眼妆与亮唇是辨识点；两侧脸宽因角度和发丝遮挡而不同，面部明暗也不对称。 成图：侧转、红妆与露齿唇形仍清楚，眼下、鼻旁和下颌能读出平滑但有体积的过渡，发丝没有被整片涂黑。
影响与取舍
精致感来自细节可读与光影连贯；把红妆当泛红去掉、把两侧脸修成对称，会削弱角色与表情。
处理与保护
分别保护眼妆、鼻孔、唇缘和下颌边界，结合侧转机位与发丝遮挡调整轮廓。

03 / 观察与判断

颈肩与尖角颈饰一起决定比例

黑发下颈侧、尖角黑颈饰、锁骨、斜向白领口及两侧肩部。

原片与成片
原图：短发与颈饰形成深色边界，肩线受侧转影响，白领口斜着跨过锁骨并在右侧形成衣褶。 成图：尖角颈饰仍有清楚轮廓，颈侧暗部、肩部亮面与斜领口继续互相解释；没有把颈饰和衣缘混成同一条黑白分界。
影响与取舍
联看头、发尾、颈侧和领口的比例；颈饰尖角与柔和皮肤之间形成清楚的材质边界。
处理与保护
联看头—颈—肩的侧转关系，保留发下阴影与领口真实斜度。保护颈饰各个尖角、吊饰与皮肤之间的间隔，不默认拉长颈部或把双肩修平。

04 / 观察与判断

T恤下缘与腰腹不能分开收窄

胸下衣褶、两手上方衣缘、裸露腰腹、侧腰与黑色松紧腰头。

原片与成片
原图：白T恤的横斜褶皱指向侧腰，下缘压在手指附近；裸腹下方被前景遮住，源图只能确认部分腰侧与衣带。 成图：T恤下缘、裸腹、侧腰到松紧腰头完整可见，裙料由腰头向下形成褶皱，衣料和腹部仍有明暗起伏。
影响与取舍
衣褶、手指与腰头共同解释体积；若只收腹部中段，衣缘和带子会留下失去支撑的折线。
处理与保护
沿衣缘—皮肤—腰头连续检查，保护衣料折叠、腹部体积和侧腰自然起伏。

05 / 观察与判断

画面左侧双带：贴肤、转折与手指压点

画面左侧下垂手指下方、侧腰到下方腰头的两条黑带。

原片与成片
原图：两条黑带在侧腰形成不同方向的可见线段，经过下垂手指附近后向下延伸；下端部分进入黑色前景遮挡，落点不完整。 成图：两条带的可见方向、手指压点与腰头关系更完整，贴肤段与斜向下段可以分别追踪，不是一条随意画在腹部上的线。
影响与取舍
带子的转折要受手和腰部支撑，否则即使位置相近也会像描线；粗细、清晰度突然变化会暴露补全接缝。
处理与保护
从每条可见起段，经指边转折到腰头逐条检查。贴肤段只需要窄而自然的接触关系，悬空段不统一加阴影；保持两带独立，不以等间距、等宽和平行作为正确标准。

06 / 观察与判断

画面右侧双带：侧腰落点与悬空受力

画面右侧拇指与食指夹持处，短上段、向侧腰下落的带段及腰头附近接点。

原片与成片
原图：右侧手指周围有运动虚影，黑带的可见段不完整，下方又与前景黑块相遇，难以一次看清全部连接。 成图：夹持处、向侧腰下落的带段和腰头更易分开读到；两侧受姿态影响，投影并不完全对称。
影响与取舍
右侧一小段材质不真实，会拖累已经成立的整体结构；对称复制左侧带形，反而可能把锚点拉到错误位置。
处理与保护
v8 借同套衣装多视角参考将右带落点放回侧腰，v9 保持位置并改善材质。沿夹持处、带段和腰头分别看位置、粗细、边缘与接触。

07 / 观察与判断

手指清晰度不能只靠重画边线

画面左侧向下伸出的指尖及其余弯指，画面右侧夹带的指腹、指甲、腕部。

原片与成片
原图：左手下垂指与其余弯指叠放，右手有真实运动虚影；手指附近同时有衣料、皮肤与细黑带，边界密集。 成图：双手形状较易读取，左侧下垂指仍指向带子，右侧夹持姿态仍围绕黑带形成空隙。
影响与取舍
手指决定带子的受力，锐利外轮廓却缺少指节和指腹过渡会变成塑料手；手部模糊也可能来自拍摄而非新增修图。
处理与保护
分别检查指尖、指甲、指腹、指缝、腕部与衣缘，保留指节与指腹的体积，结合原有运动虚影判断边缘。

08 / 观察与判断

保留景深，让人物与背景自然分离

左侧失焦白发人物、头顶散景灯、白扶手横线、黑发与白T恤边缘。

原片与成片
原图：背景已有浅景深，左侧白发人物与白扶手失焦，黑色天花板灯点柔和；主体白衣受暖光，黑发仍有细节。 成图：背景人物仍在左侧失焦区域，灯点与扶手维持柔和层次；主体放大后黑发、颈饰、白衣和皮肤的分离更突出。
影响与取舍
已有景深足以帮助主体突出，不需要把所有路人或亮点都删除；画面重排后若背景横线断裂、发缘出现白边，就会失去自然空间。
处理与保护
沿扶手与主体边缘看连续性，联看白衣纹理、皮肤暖色与黑发层次。

REVIEW / 实际成片复看

这一类照片怎样验收

  1. 适屏联看头、颈、肩、腰腹和双手，确认脸部侧转、两手牵带与腰头连接清楚。
  2. 分别沿左右两条带看完整路径：可见起段、夹持或压点、贴肤与悬空段、侧腰及腰头，不以完全对称或复制像素距离判断正确。
  3. 放大看双手与衣缘：手指数量和方向可读，指节、指腹、腕部、下摆连续；原有运动虚影与新增接缝分开判断。
  4. 联看细带的粗细、边缘与接触阴影，保留T恤和裙料的褶皱与纹理。
