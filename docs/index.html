自然美型的处理重点

把人物、场景和细节一起看。

调整幅度依照片和你的目标决定。每一处变化，都要回到整张照片检查。

01 / 人物

肤质、五官与身形

分清肌理、妆面、透视与姿态，评估脸颈、肩腰和腿脚的协调，保护本人特征和关节。

02 / 场景

构图、光色与背景

判断留白、动作路径和具体干扰，处理肤色和彩光衔接；背景弱化、清理或替换先说明范围。

03 / 连接

衣装、手与道具

从握点、衣带、边缘到补全内容，联看整条连接。放大检查接缝、材质和新增损伤。
