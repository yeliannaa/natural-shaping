1. 准备环境和一张原片

在支持 Agent Skills 的 Codex 环境中使用本技能。确认 Codex 能读取你的照片、查看图像，并能调用至少一种实际图像编辑工具。

一张可读取的原片

优先提供原始照片文件。可以在聊天中附图，或给出本地绝对路径；请允许应用访问所在目录。

明确的输出目录

给本次任务一个独立目录，保存草图、预览和成片。原片只读，输出不要写入技能安装目录。

安装技能不会同时安装修图工具。内置图像编辑可承担生成路线；Qwen 可选。需要原生 PS 操作或分层 PSD 时，再准备 Photoshop 与可执行连接。当前没有实际图像编辑工具时，只能进行诊断和方案说明。

2. 安装完整技能包

以下命令沿用仓库已验证的 Skills CLI 1.7.1，需要 Node.js 22.20.0 或更高版本。在你准备使用技能的项目目录打开终端，先查看仓库中的技能：

终端 · 列出技能
npx skills@1.7.1 add yeliannaa/natural-shaping --list

为当前项目中的 Codex 复制安装：

终端 · 项目内安装
npx skills@1.7.1 add yeliannaa/natural-shaping --skill natural-shaping --agent codex --copy --yes

项目安装位置为 .agents/skills/natural-shaping。让 Codex 识别新增技能后再调用；仓库的安装验证覆盖技能发现和复制安装，具体图像编辑能力仍需在你的环境中检查。也可查看已公开的 skills.sh 技能条目。

也可以手动复制

从 GitHub 仓库下载或克隆文件，将完整的 natural-shaping/ 文件夹放入目标应用支持的技能目录，保持内部结构。不要只复制 SKILL.md。首次能力检查见 移植说明。

3. 提供照片、目标和输出目录

先选一张照片，把最在意的效果和保护点说清楚。文件路径示例需要替换成你实际的路径；也可以直接附图，并把“源图”一行改为“本次附图”。

4. 先看源图草图，再确认范围

第一次处理新图，或准备完整重修时，Codex 应先解释构图，并展示基于原片的标注草图。你看到的应当是这张照片的方案：哪些区域调整、哪些关系保护，缺失内容中哪些属于推断。

  1. 核对构图和保护点

    检查画边、留白、动作路径与遮挡。再联看脸、假发颈肩、胸腰髋、腿脚和道具，确认整张照片的方向。

  2. 说出需要改动的范围

    可以要求减弱某处调整，保留某个背景元素，或选择另一种裁幅。不要把不同照片的草图当作本图确认。

  3. 明确确认后开始执行

    你可以使用下面的回复，并按实际方案修改。Codex 在确认范围内选择当前可用工具进行编辑。

复制并按实际草图调整 · 确认示例
确认按刚才展示的本图方案执行。
请保留已标明的妆造、关节、衣装和道具保护点。
修后展示整图对照与关键细节，并给出输出目录中的实际成片文件。

同一已确认方案内的局部返修沿用有效确认。新图、完整重修或新增构图、重建范围，按技能规则执行对应草图确认。

想先了解草图应该解释到什么程度，可以看 狩司司 110、114 原片方案拆解。

5. 检查整体、细节和实际文件

看过整图，再放大检查关键处。皮肤应细腻且可信，妆面和本人特征清楚；脸颈手光色协调；手、衣带、握点、鞋和道具连接完整，边缘没有明显涂抹、灰边或接缝。

不同裁幅或重建背景的整图可以按同一展示高度比较观感；检查细节时应另看同倍率局部。整图等高展示不代表像素已对齐。

最后确认你拿到的是可打开的实际文件，并核对目录、尺寸和版本。你认可整张成片后，再记录为终稿；仅局部满意或技术检查通过，不能代替整体认可。分层 PSD 只在当前工具实际支持时交付。

工具按执行路线准备

Codex 负责分析、选路、调用工具和验收，不要求每张照片同时使用全部后端。先确认你当前应用里哪些工具真实可用，再选择对应路线。

能力或工具什么时候需要实际边界
文件读取与图像查看源图分析、草图沟通和成片复核必须能读到本次照片和输出文件。
内置图像编辑当前应用支持时，可独立承担生成编辑路线候选仍要检查；是否采用整图、局部融合或仅作参考，依实际结果决定。
Qwen可选生成后端模型、程序、资源和连接由当前环境提供；本包不附模型或账户。没有 Qwen 时，可使用可用的内置图像编辑。
Photoshop 与可执行连接原生 PS 精修、精确局部调整或分层 PSD 交付需能执行 ExtendScript。没有 PS 时仍可使用其他可用编辑路线，交付其实际支持的栅格格式。
PowerShell / Python 3.11+使用包内 PNG 检查 / 无损压缩脚本时按需准备；包内没有自动身体识别或液化接口。自动主体蒙版另有可选依赖。

如果当前没有任何可执行图像编辑工具，Codex 可以继续看图诊断和方案说明；提示词、草图或方案不能作为修后成片交付。详细环境与依赖见 移植说明和 仓库能力边界。
